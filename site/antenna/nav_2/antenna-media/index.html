Notes

  • The SolidWorks Bundle (.zip) contains all three components as native .SLDPRT files, and the .SLDASM full assembly file — along with every part it references (fasteners, washers, nuts, heat-set inserts, and any other hardware CAD used in the assembly). Everything needed to open the complete assembly without missing-reference errors is in this one zip. Requires SolidWorks to open.
  • The Neutral Bundle (.zip) contains the same three components in .STEP format, compatible with most CAD software — recommended if you don't have access to SolidWorks.
  • The STL Bundle (.zip) contains print-ready mesh geometry for all three components, for slicing in any FDM slicer.
  • The Print Project (.3mf) is a Bambu Studio project containing all three components along with the validated print settings and slicer profile used for production. Requires Bambu Studio to open.
