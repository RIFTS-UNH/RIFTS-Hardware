### Notes

- The **SolidWorks Bundle** (.zip) contains all three components as native `.SLDPRT` files and requires SolidWorks to open.
- The **Neutral Bundle** (.zip) contains the same three components in `.STEP` format, compatible with most CAD software — recommended if you don't have access to SolidWorks.
- The **STL Bundle** (.zip) contains print-ready mesh geometry for all three components, for slicing in any FDM slicer.
- The **Print Project** (.3mf) is a Bambu Studio project containing all three components along with the validated print settings and slicer profile used for production. Requires Bambu Studio to open.
- The **Full SolidWorks Assembly** (.zip) contains the complete `.SLDASM` file along with **every part it references** — the three printed components, all fasteners, washers, nuts, heat-set inserts, and any other hardware CAD used in the assembly. SolidWorks assemblies fail to open correctly if any referenced part is missing, so this is provided as a single self-contained download rather than requiring you to track down each fastener individually. Recommended if you want the complete assembly to open without missing-reference errors.
