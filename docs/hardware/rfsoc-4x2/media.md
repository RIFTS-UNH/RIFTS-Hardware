### Notes

- The **.STEP** file is a neutral-format CAD export compatible with most major CAD software (SolidWorks, Fusion 360, OnShape, etc.), recommended for general viewing, integration, and reference use.
- The **.pda** file is intended to be opened inside *Protocase Designer*, free CAD software maintained by Protocase, and reflects the exact fabrication package used for manufacturing this enclosure.
- The **.SVG** file is a vector logo suitable for engraving or printing on the enclosure panel during manufacturing.
